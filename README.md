## ✦ The Build

**Logout Animation — Series 01** is a polished frontend interaction experiment built around one simple idea:

> **What if clicking Logout felt like an experience instead of a state change?**

Instead of instantly replacing the interface, the interaction moves through a sequence:

```text
LOGOUT
   ↓
Button Morph
   ↓
Dashboard Exit
   ↓
Door / Exit Scene
   ↓
Signed Out
   ↓
Enter Again
```

The entire experience is built from scratch using **HTML, CSS and JavaScript**.

---

## 🎬 The Experience

### 01 — Dashboard

The experience starts inside a minimal workspace dashboard featuring:

* Workspace identity
* User welcome section
* Project statistics
* Activity status
* Session information
* Interactive Logout control

The interface uses a clean editorial visual language with a dark outer canvas and light workspace surface.

---

### 02 — Logout Button Morph

Clicking **Logout** doesn't immediately switch screens.

The button transforms first.

```text
┌─────────────────┐
│     Logout      │
└─────────────────┘

        ↓

       ┌───┐
       │ → │
       └───┘
```

The text fades away while the button changes shape and reveals a small exit/door interaction.

---

### 03 — Dashboard Exit

The dashboard then moves away from the user.

The cards progressively translate and fade, creating a directional transition rather than a simple opacity change.

The interaction is controlled through JavaScript state classes and timed transitions.

---

### 04 — The Exit Scene

The interface transitions into a dedicated exit moment:

**See you**
***next time.***

Alongside the message, an animated door opens to reinforce the idea of leaving the workspace.

---

### 05 — Signed Out

The experience settles into a clean final state:

> **Signed out.**

**Your workspace is secure.**

A simple **Enter again** action allows the experience to be replayed without refreshing the page.

---

## ✨ Interaction Details

| Interaction      | Experience                    |
| ---------------- | ----------------------------- |
| Logout hover     | Subtle lift + light sweep     |
| Logout click     | Button morph                  |
| Dashboard exit   | Directional movement + fading |
| Exit scene       | Door reveal animation         |
| Signed-out state | Smooth scale/fade entrance    |
| Enter again      | Reverse transition            |
| Mobile           | Responsive layout             |
| Reduced motion   | Respects user preference      |

## 🧠 Under the Hood

The interaction is intentionally lightweight.

JavaScript controls the main state transitions by applying classes to the workspace window:

```text
.logging-out
      ↓
.exit-phase
      ↓
.signed
```

The timing sequence handles the transition between each visual state while CSS performs the actual animation work.

This keeps the interaction simple, reusable and framework-free.

## 🎯 Why This Build?

Logout is normally treated as a functional action.

This build explores how a tiny interaction can become part of the overall product experience.

Instead of:

```text
Click → Gone
```

the interaction becomes:

```text
Click
  ↓
Feedback
  ↓
Motion
  ↓
Transition
  ↓
Completion
```

**The goal isn't to make a logout button complicated.**

It's to make the interaction feel intentional.
